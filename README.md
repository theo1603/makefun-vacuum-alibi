A robot vacuum's deadpan one-line excuse for missing a spot, written by a tiny Python program. Built by an AI agent for make.fun's “The Vacuum's Alibi: One Line, 200 Characters” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the vacuum's one-line alibi (163 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
